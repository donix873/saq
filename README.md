# SAQ — проверка подозрительных сообщений

SAQ — двуязычное веб-приложение для предварительной проверки сообщений и ссылок на признаки социальной инженерии. Оно объясняет найденные сигналы и предлагает безопасные следующие шаги.

## Что уже работает

- Анализ русского и казахского текста.
- Проверка ссылок без их открытия.
- Поиск срочности, угроз, запроса кодов и денег, удалённого доступа и других признаков.
- Проверка подмены известных доменов (`Kaspi`, `Halyk`, `eGov`, `Forte`, `Jusan`).
- Понятный уровень риска, объяснение и план действий.
- Переключение русского и казахского интерфейса.
- Локальная история проверок с отключением и полным удалением.
- Адаптивный интерфейс для телефона, планшета и компьютера.

Текущая версия использует объяснимые правила и работает полностью в браузере. Она не отправляет проверяемый текст на сервер и не требует API-ключей.

## Запуск на своём компьютере

1. Установите [Node.js](https://nodejs.org/) версии 20 или новее.
2. Скачайте репозиторий и откройте терминал в его папке.
3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите приложение:

   ```bash
   npm run dev
   ```

5. Откройте адрес `http://localhost:4173`.

Остановить сервер можно сочетанием `Ctrl+C`.

## Бесплатная публикация

### Вариант 1 — Vercel

1. Создайте аккаунт на [vercel.com](https://vercel.com/) через GitHub.
2. Нажмите **Add New → Project**.
3. Выберите репозиторий `donix873/saq`.
4. Vercel автоматически определит Vite.
5. Проверьте настройки: Build Command — `npm run build`, Output Directory — `dist`.
6. Нажмите **Deploy**.

### Вариант 2 — Netlify

1. Создайте аккаунт на [netlify.com](https://www.netlify.com/).
2. Выберите **Add new site → Import an existing project**.
3. Подключите GitHub и выберите репозиторий.
4. Укажите команду `npm run build` и папку публикации `dist`.
5. Нажмите **Deploy**.

## Важное ограничение

SAQ не гарантирует, что сообщение безопасно или мошенническое. Это помощник для принятия решения, а не замена банку, полиции или специалисту по кибербезопасности.

Для следующего этапа можно добавить серверный AI-анализ через защищённый backend. Секретный API-ключ должен храниться только на сервере, например в environment variables Vercel, и никогда не попадать в React-код.
